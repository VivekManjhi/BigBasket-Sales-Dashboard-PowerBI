# 🛒 BigBasket Sales Dashboard - Power BI

## 📌 Project Overview

This project is an interactive Power BI dashboard built using the BigBasket sales dataset. It provides meaningful business insights through KPIs, charts, and dynamic filters to support data-driven decision-making.

## 📊 Key Performance Indicators

- 💰 Total Sales: $1.20M
- 🛒 Total Items Sold: 9K
- 📈 Average Sales: 140.99
- ⭐ Average Customer Rating: 3.92

## ✨ Dashboard Features

- Interactive Filters
- Sales by Item Type
- Sales by Fat Content
- Outlet Analysis
- KPI Cards
- Dynamic Charts
- Data Table

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization
